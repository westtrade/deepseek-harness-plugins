# `dsh-session-gate`

Доступ к инструментам **в отдельном чате** DeepSeek Harness: рядом с выпадайкой
«Workspace Write» в композере появляется кнопка **«Доступ»**, которая открывает
модалку с галочками:

- **какие MCP-серверы подключены к этому чату** — снятая галочка убирает все
  инструменты сервера (`mcp__<сервер>__*`) из того, что видит и может вызывать
  модель именно в этом чате;
- **может ли агент читать фотографии** — переключатель инструмента `read_image`
  (PNG/JPEG/WebP/GIF). Рядом показано, принимает ли изображения модель,
  выбранная в чате; если текущая модель текстовая, плагин прямо говорит, что
  прочитать фото не получится.

Кнопка есть и в новом чате (сессия уже создана, просто пустая), и в разговоре —
это одна и та же точка композера. Изменения действуют со следующего шага модели
и сохраняются на диск, так что переживают перезапуск и перезагрузку страницы.

## Что по умолчанию

Всё **выключено**: в новом чате ни один MCP-сервер не подключён и `read_image`
недоступен. Это осознанно — доступ выдаётся явно, галочками. Новый
MCP-сервер, подключившийся позже, тоже не появляется ни в одном чате, пока его
не отметят: хранилище держит **список разрешённого**, а не исключений.

Прежние записи (версия 1, где по умолчанию было «всё включено») при чтении
сбрасываются на новые умолчания: список исключений нельзя достоверно обратить
в список разрешений, а записанное там «включено» чаще было старым умолчанием,
чем выбором человека. Файл переписывается в версию 2 при первом сохранении.

## Как это работает

Веб-часть рисует кнопку и модалку из штатных примитивов оболочки
(`Modal`, `Button`, `Switch`, `IconChecklistOutline14`) — то есть тем же
языком, что и выпадайка «Workspace Write», а не самодельными виджетами.

Хост-часть:

- хранит выбор в `$DSH_HOME/session-gate.json` (один файл, запись через
  временный файл + `rename`), по записи на чат: `{ mcpOn: [...], photos: bool }`,
  где `mcpOn` — разрешённые серверы;
- на каждый живой агент вешает `ctx.tools.restrict({ deny })`: в `deny` попадают
  инструменты всех серверов, которых нет в списке разрешённых, и `read_image`,
  пока фото не разрешены. Так они исчезают из схем и вызовов **только у этого
  чата**; ограничение заменяется при каждом изменении и снимается при
  уничтожении агента;
- пересобирает ограничение по событию `tools/change`, поэтому сервер,
  подключившийся (или обновивший список инструментов) позже, тоже попадает под
  выбор, уже сделанный в чате;
- определяет модель чата по ожидающей/последней выборке и отдаёт в интерфейс,
  принимает ли она изображения (`inputModalities` из `ctx.llm`).

Серверы берутся из зарегистрированных инструментов с именами
`mcp__<serverName>__<tool>`, поэтому список всегда соответствует тому, что
реально подключено.

Ограничение — это именно доступ **сессии**: процесс MCP-сервера и его
подключение остаются общими для всего профиля, но модель этого чата его
инструментов не видит и вызвать не может. `read_image`, как и любой штатный
инструмент, заодно перестаёт занимать место в схемах.

## Установка

```sh
# из этого монорепо, как остальные плагины:
ln -s "$PWD/dsh-session-gate" ~/.dsh/profiles/node_modules/dsh-session-gate
```

и строка в `~/.dsh/profiles/web/cordis.patch.yml` (в общий список `insert`):

```yaml
    - id: session-gate
      # `file://` с `?rev=N`: правка `rev` перечитывает хост-модули без
      # перезапуска Web-сервера (см. комментарий у соседних плагинов).
      name: 'file:///home/io/.dsh/profiles/node_modules/dsh-session-gate/lib/index.js?rev=1'
      config: {}
```

Патч профиля перечитывается на лету (`patchReload: live`), но клиентский бандл
подхватывается после перезагрузки страницы в браузере.

## Проверки

```sh
node scripts/host-test.mjs    # маршрут, ограничения инструментов, модель, хранилище
node scripts/client-smoke.mjs # бандл: слот, примитивы, словари, стили
```

## Ограничения

- Галочка «фотографии» управляет инструментом `read_image`. Если картинку
  прислал сам человек вложением или её вернул MCP-инструмент, это отдельный
  путь; плагин его не трогает — и для текстовой модели харнесс и так заменяет
  изображения детерминированным текстом.
- Действие «по умолчанию» распространяется и на чаты без записи: экран не
  показывает ничего отмеченным, пока человек сам не поставит галочки.
- MCP-серверы, зарегистрированные внутри конкретного агент-пресета (agent-scoped
  MCP), ограничению не подлежат: `tools.restrict()` работает с глобальным слоем.
- Колбэк модалки — «Закрыть»: сохраняется сразу при каждом клике, отдельной
  кнопки «Сохранить» нет намеренно.
